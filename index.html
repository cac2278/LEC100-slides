Finding books

Call numbers are a book’s address

A call number tells you where a book belongs on the shelf.

We organize books using the Library of Congress Classification (LCC) system.

LCC groups books by subject, so books about similar topics are usually shelved near one another.

Example call number

PN 1995
.M68 2024

You do not need to memorize what every part means.

For today, remember: find the call number in the catalog → use it to find the book on the shelf. If you get stuck, ask us.

View an outline of the Library of Congress Classification System

A note about the language: Some names and terms used in Library of Congress classifications are outdated, inaccurate, or offensive. Librarians and other information professionals are working to change harmful terminology and make these systems more accurate and inclusive.

Before we practice

Remember these three things

  1. The library is more than books. It is a place, a set of resources, and a group of people who can help you.
  2. You can ask for help early. You do not have to wait until you are completely stuck.
  3. The library is here and online. Lenox Library is in Allen Hall, and library resources are available through the UW–Whitewater Libraries website.
